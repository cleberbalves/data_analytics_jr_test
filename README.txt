Projeto de Análise de Dados da Educação em São Paulo
Visão Geral
Este projeto envolve a análise de dados educacionais da cidade de São Paulo. O objetivo principal é entender melhor as informações disponíveis nas tabelas e criar visualizações úteis para extrair insights. As seguintes etapas foram realizadas:

Tratamento dos Dados

Os dados foram carregados nas tabelas.

A coluna name está exibindo todos os nomes das colunas concatenados em um único valor com maiúsculas e minúsculas.

Criação do Banco de Dados

Foi criado o banco de dados educação_sp.

A visualização do banco de dados foi feita utilizando o DBeaver.

Relacionamento das Tabelas

O vínculo entre as tabelas escolas e alunos foi criado conforme o arquivo escola_alunos.

Instalação de Ferramentas

Foram instalados o Jupyter, Pandas e Matplotlib para a análise dos dados.

Notebook de Análise Exploratória

Foi criado um notebook para a análise exploratória dos dados.

Visualização dos Dados

As visualizações foram feitas utilizando a biblioteca Streamlit.

Como Executar o Projeto
Clone este repositório:

bash
git clone https://github.com/seu_usuario/seu_repositorio.git
Navegue até o diretório do projeto:

bash
cd seu_repositorio
Crie um ambiente virtual e ative-o:

bash
python -m venv venv
source venv/bin/activate # Para Linux/Mac
venv\Scripts\activate # Para Windows
Instale as dependências:

bash
pip install -r requirements.txt
Abra o Jupyter Notebook e execute a análise exploratória:

bash
jupyter notebook
Execute a aplicação Streamlit para visualização dos dados:

bash
streamlit run app.py
